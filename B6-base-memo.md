# Target Ubuntu 24.04 LTS for both images

The owner's deciding criterion is straightforward installation of Blockstream Satellite. Target **Ubuntu 24.04 LTS (Noble), amd64**, for the sitting stick and the node. Blockstream documents an Ubuntu installation through its own APT repository, `ppa:blockstream/satellite`. W5 can install the receiver software while preparing the node. The sitting stick uses only its own package list. [Blockstream installation guide](https://blockstream.github.io/satellite/doc/software.html)

## Why Noble

Blockstream's Noble index contains `blockstream-satellite`, `bitcoin-satellite`, `gr-dvbs2rx`, `leandvb` and `tsduck`. The Ubuntu 26.04 (Resolute) index returned HTTP 404 on 2026-11-19. Debian 12 also has vendor packages. Blockstream documents its GNU Radio SDR receiver for Ubuntu 22.04 and later. The Debian 13 diagnostic build preceded the owner's installation criterion. Its software and terminal observations remain historical evidence. [Noble packages](https://ppa.launchpadcontent.net/blockstream/satellite/ubuntu/dists/noble/main/binary-amd64/Packages.gz) · [Debian suites](https://aptly.blockstream.com/satellite/debian/dists/) · [Blockstream SDR guide](https://blockstream.github.io/satellite/doc/sdr.html)

In a disposable VM, APT installed all five packages together with normal recommended dependencies into an authenticated Ubuntu Base 24.04.5 amd64 filesystem. The package audit was clean, and blocksat-cli and the satellite-enabled bitcoind both ran. Using the documented PPA command and the installed CLI, the standalone, USB and SDR dependency installations all completed. The PPA signing fingerprint was checked against Launchpad and scoped to that repository. The W5 release should retain the PPA's signed metadata and referenced package files with their hashes separately from the Canonical snapshot. The upstream installer checks the distribution ID directly. Keep ID=ubuntu and VERSION_CODENAME=noble on the node, with VARIANT_ID=refugium-node identifying its role. The TBS driver installer asks for headers matching the running kernel, so W5 must supply matching headers or integrate the driver into Refugium's node kernel. Acceptance covers installing the software for all three receiver types. The user sets up the reception equipment, aligns the dish and checks the live signal. [Install test](evidence/noble-receiver.md) · [Launchpad archive](https://launchpad.net/~blockstream/+archive/ubuntu/satellite) · [Receiver installer source](https://github.com/Blockstream/satellite/blob/v2.5.1/blocksatcli/dependencies.py#L112) · [TBS USB guide](https://blockstream.github.io/satellite/doc/tbs.html)

## Building the images

Build the two root filesystems from the same signed Ubuntu snapshot covering noble, noble-updates and noble-security. The builder is a pinned Debian VM running mmdebstrap. The Ubuntu archive keyring pinned in `image/base.lock.json` comes from `usr/share/keyrings/ubuntu-archive-keyring.gpg` in Canonical's signed Ubuntu Base 24.04.5 amd64 release (tar SHA-256 `e77b6f10c2590cef872b33ee9f635a0e3fd1f57fb074c0e52b5c7f56147a0c86`). Each role has its own kernel configuration from one authenticated Linux source. The stick has no satellite or Bitcoin Core packages, network drivers or swap. See mnemonic-refugium `design/DESIGN_refugium_os.md@c026b9b159:L110`. [Ubuntu snapshots](https://snapshot.ubuntu.com/) · [Ubuntu Base image and signed checksums](https://cdimage.ubuntu.com/ubuntu-base/releases/24.04/release/)

Reuse the wallet's pinned Nix build for the portable Linux mr-gui and the engraving project's pinned Nix build of patched picotool where they pass image integration. The earlier wallet G-15 design called for offline rebuilding from a full source archive. Carry the source archive question into release review. Matching two complete images assembled from the same binary packages establishes repeatable assembly. A source-rebuild claim requires independent evidence. See refugium-wallet `design/SPEC_framework_slint.md@5da720457b:L1123`, `flake.nix@5da720457b:L164` and mnemonic-engrave `flake.nix@8829885954:L30`. [Nix runtime dependencies](https://nix.dev/manual/nix/2.32/command-ref/nix-store/query)

For each update, build both images twice, compare each role's complete bytes, sign a manifest binding role, version, length and hash, and verify the replacement medium by readback. The sitting machine stays offline.
